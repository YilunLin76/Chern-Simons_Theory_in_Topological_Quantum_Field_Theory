\section{Mathematical Foundations}\label{sec: Mathematical Foundations}
\par This section aims to provide readers with an introduction to the fundamental mathematics which is necessary for understanding the Chern-Simons theory we will discuss in section \ref{sec: Chern-Simons Theory}. The introduction in this section will cover topics ranging from basic concepts in differential geometry to the key mathematical structures in the background of Chern-Simons theory, including the characteristic classes and Chern-Simons form. 
\par We hope this mathematical background would be beneficial to readers, especially to those who are in the physics community and do not have sufficient knowledge of differential geometry. For readers already familiar with basic notions of differential geometry, it might be appropriate to skip some parts of this section and proceed directly to the discussion on characteristic classes and Chern-Weil theory. 
\subsection{Differential Geometry and Fiber Bundles}\label{subsec: Differential Geometry and Fiber Bundles} % 6 pages
\par It is well known that a topology $\mathrm{T}$ on a nonempty set $X$ is a collection of subsets of that set $X$, such that: (i) both the empty set $\emptyset$ and $X$ itself are elements in $\mathrm{T}$; (ii) for any two subsets of $X$ which are elements in $\mathrm{T}$, their intersection is also an element of $\mathrm{T}$; (iii) the union of any collection of sets from $\mathrm{T}$ is also an element of $\mathrm{T}$. A topological space is defined to be a nonempty set with such a given topology $\mathrm{T}$ on it. Based on this simple definition, the so-called open sets in a topological space are just the sets in $\mathrm{T}$, and the closed sets are just those which are not in $\mathrm{T}$. 
\par Suppose $M$ is already a topological space with a topology $\mathrm{T}$, then it is called a topological manifold if and only if it satisfies the following conditions.
\begin{enumerate}[label=(\roman*)]
    \item \textbf{Hausdorff property:} For arbitrary $\mathbf{x}_{1},\,\mathbf{x}_{2}\in M$, if $\mathbf{x}_{1}\neq\mathbf{x}_{2}$, then there exists $\mathcal{O}_{1},\,\mathcal{O}_{2}\in\mathrm{T}$, $\mathcal{O}_1\neq\mathcal{O}_{2}$, such that $\mathbf{x}_{1}\in\mathcal{O}_{1}$ and $\mathbf{x}_{2}\in\mathcal{O}_{2}$.
    \item \textbf{Second countability:} For the topology $\mathrm{T}$, there exists a countable basis $\mathcal{B}=\{U_{i}\}_{i\in\mathbb{N}}$, such that any set from $\mathrm{T}$ is the union of some of these $U_{i}$.
    \item \textbf{Local Euclidean property:} For arbitrary $\mathbf{x}\in M$, there exists a homeomorphism $\phi:U\rightarrow V$, in which $U$ is an open neighborhood of $\mathbf{x}$ and $V$ is an open set in $\mathbb{R}^{n}$.
\end{enumerate}
Topological manifold is a fundamental notion in differential geometry. It has broad applications in theoretical physics, notably in general relativity and topological quantum field theory.
\par A chart on a topological manifold $M$ is defined to be an ordered pair $\left(U,\phi\right)$, where $U$ is an open set on $M$ and $\phi:U\rightarrow\mathbb{R}^{n}$ is a homeomorphism. Then we call $\mathcal{A}=\{\left(U_{\alpha},\phi_{\alpha}\right)\}$ an atlas on $M$ if and only if it satisfies: (i) each $\left(U_{\alpha},\phi_{\alpha}\right)\in\mathcal{A}$ is a chart on $M$; (ii) the union of all these $U_{\alpha}$ in $\mathcal{A}$ could cover the entire topological manifold $M$. It should be noted that, although the most general definition in pure mathematics allows an atlas to contain uncountably many charts, it is customary to assume that only a countable charts exist in each atlas, in order to ensure that the manifold is second-countable. This property of second countability is required in most physical applications. Accordingly, we will restrict the amount of charts in a feasible atlas to be countable in this paper.
\par In physics contexts, it is customary to consider only atlases that are differentiable. A differentiable atlas is an atlas in which for arbitrary two charts $\left(U_{\alpha},\phi_{\alpha}\right)$ and $\left(U_{\beta},\phi_{\beta}\right)$ in it, if $U_{\alpha}\cap U_{\beta}\neq\emptyset$, then their transition function $\phi_{\beta}\circ\phi_{\alpha}^{-1}:\,\phi_{\alpha}\left(U_{\alpha}\cap U_{\beta}\right)\rightarrow\phi_{\beta}\left(U_{\alpha}\cap U_{\beta}\right)$ is smooth, that is, infinitely differentiable $\left(C^{\infty}\right)$. 
\par Suppose that $M$ is a topological manifold with a differentiable atlas $\mathcal{A}$. This differentiable atlas $\mathcal{A}$ is termed a maximum differentiable atlas if and only if it satisfies the following requirement: for any chart $\left(U,\phi\right)$, once the transition functions between it and arbitrary charts in $\mathcal{A}$ are infinitely differentiable, this chart $\left(U,\phi\right)$ must be already contained in $\mathcal{A}$. This means that there does not exist any additional chart that can be added into $\mathcal{A}$ without violating its previous structure of differential operator. The definition of a maximum differentiable atlas is formulated based on the idea of completeness of mathematical structure. A maximum differentiable atlas of a manifold is more commonly referred to as a differentiable structure. 
\par A topological manifold $M$ equipped with a differentiable structure is termed a differentiable manifold. The differentiable manifold is often denoted as $\left(M,\mathfrak{F}_{M}\right)$, where $\mathfrak{F}_{M}$ refers to the given differentiable structure of this differentiable manifold. 
\par There are several crucial types of maps between differentiable manifolds that we have to clarify before introducing the notion of fiber bundle. For a differentiable manifold, we customarily term the local coordinate functions $\phi_{\alpha}\left(\mathbf{x}\right)$ $\left(\forall\,\mathbf{x}\in U_{\alpha}\subset M\right)$ provided by charts in the differentiable structure a local coordinate system. A smooth map between two differentiable manifolds $\left(M,\mathfrak{F}_{M}\right)$ and $\left(N,\mathfrak{F}_{N}\right)$ is a function $f:M\rightarrow N$ whose expressions in local coordinate system are smooth.
